วิธีเอาเว็บไซต์ขึ้น GitHub Pages

คุณสามารถเปิดใช้งานเว็บไซต์ประวัติส่วนตัวนี้แบบออนไลน์ฟรี 100% ผ่าน GitHub Pages ได้ง่ายๆ ดังนี้:

  1. บันทึกไฟล์นี้: ตั้งชื่อไฟล์นี้ว่า index.html
  2. สมัคร / เข้าสู่ระบบ GitHub: ไปที่ github.com
  3. สร้าง Repository ใหม่: กดปุ่ม "New" แล้วตั้งชื่อ เช่น my-academic-portfolio (เลือกตั้งค่าเป็น Public)
  4. อัปโหลดไฟล์: คลิก "uploading an existing file" แล้วลากไฟล์ index.html ใส่เข้าไป จากนั้นกด "Commit changes"
  5. เปิดใช้งาน GitHub Pages:
    • ไปที่แถบเมนู Settings ของ Repository นั้น
    • คลิกเมนู Pages ด้านซ้ายมือ
    • ใต้คำว่า Build and deployment เลือก Source เป็น Deploy from a branch
    • เลือก Branch เป็น main (หรือ master) และโฟลเดอร์เป็น / (root) แล้วกด Save
  6. เรียบร้อย! รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://username.github.io/my-academic-portfolio
